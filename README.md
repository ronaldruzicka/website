# Personal Portfolio

A personal developer portfolio built with **SvelteKit** and **Panda CSS**.

## Project structure

```text
/
├── static/              # Static assets (favicon, images)
├── src/
│   ├── app.css          # Panda CSS layer entry
│   ├── app.html         # HTML template
│   ├── lib/
│   │   ├── components/  # Svelte components
│   │   └── utils/       # Shared utilities
│   └── routes/          # SvelteKit file-based routing
│       ├── +layout.svelte
│       └── +page.svelte
├── panda.config.ts      # Panda CSS theme and tokens
└── styled-system/       # Generated by Panda (gitignored)
```

## Commands

| Command         | Action                                      |
| :-------------- | :------------------------------------------ |
| `bun install`   | Install dependencies                        |
| `bun run dev`   | Start dev server (default: localhost:5173)   |
| `bun run build` | Build for production                        |
| `bun run preview` | Preview the production build locally     |
| `bun run check` | Run svelte-check                            |

## Deployment

The project uses `@sveltejs/adapter-auto`. To deploy to a specific platform, install the matching adapter (e.g. `@sveltejs/adapter-vercel`, `@sveltejs/adapter-static`) and configure it in `svelte.config.js`.
